## 1. 选择原则

不要先问“放哪些仙侠元素”，先确定画面中的“门槛—行者—彼岸”关系。

建筑可以承担三种功能：

- **边界**：檐、柱、墙、松枝或洞门从画面边缘裁入，建立观看门槛。
- **路径**：长阶、桥、回廊、铺装节奏、水渠或光带把尺度锚与目的地连接起来。
- **目标**：远端殿门、天光、山峰、月轮或神树承接视线。

每张选一种为主、另一种为辅。不要让边界、路径和目标平均用力，也不要同时设多个宏观几何。

当画面表现可居住的天界聚落时，再选择一种总体拓扑：沿轴线逐级升高、依悬崖分层展开、多个宫岛由桥廊连成网络，或围绕一个自然／建筑核心组织。始终保留一个统领区域、若干从属区域和可见交通联系，避免宫殿像贴纸一样散落在雾里。

## 3. 八种构图原型

### A. 框中借景

**用途**：远眺、揭示、等待、产品展示、人物会晤。

**几何**：顶部飞檐＋左右柱、松枝或暗墙构成不完整画框；远景主宫阙或自然奇观偏置，另一侧保留连续云海。

**镜头**：28–50mm 中广角感；相机像站在真实露台、殿门或廊下；垂直线稳定。

**层次**：暗前框 → 人物或器物所在平台 → 中景开放边缘／松 → 云海遮挡带 → 远端宫阙／神木 → 天际。

**人物**：下方中轴或三分区；以单人、双人或小组为宜。

**避免**：把整个圆门、宫殿和人物全部居中；前框过厚吞掉主景；远景像旅游明信片。

### B. 中轴朝圣

**用途**：抵达、觐见、登临、命运选择、封面主视觉。

**几何**：道路、长阶、长桥、铺装分缝、人物与远端大殿沿单一竖轴排列；建筑宏观对称，自然细节轻微破缺。

**镜头**：35–85mm；长阶可用中长焦压缩，云庭可用 24–35mm 展开。

**层次**：近台阶高差／桥面分缝 → 人物 → 递减构件 → 云墙 → 远端天门／主殿 → 天空。

**人物**：位于最下方中央，必须有接触阴影；人物与终点之间保持连续通路。

**避免**：道路与门殿中轴错位；左右柱距指向不同消失点；云完全遮断路径。

### C. 神殿天光

**用途**：启示、审判、觉醒、受封、祭仪。

**几何**：深井式多层殿阁或高耸中庭；柱列和层檐向中央收束；顶部开口释放唯一垂直光柱。

**镜头**：20–28mm 广角感，但避免鱼眼；相机低位、端正、居中。

**层次**：近景暗柱／云 → 中层柱廊 → 横向台基与人物 → 层层楼阁 → 屋顶开口和光柱。

**人物**：极小，站在光柱落点或稍离轴位置；轮廓清楚，不做面部肖像。

**避免**：额外加入巨月、神树或多束能量光；顶光没有真实开口；室内云像舞台烟机。

### D. 横向悬跨

**用途**：相遇、守候、过境、护送、世界展示。

**几何**：桥、廊或宫殿跨过画面上中部；一侧巨殿被主动裁切形成 L 形重块，下方为连续云海。

**镜头**：50–85mm 中长焦侧视；用重复柱、桥面分缝和屋檐缩尺建立距离。

**层次**：近侧殿体 → 横桥人物 → 远端廊柱 → 瀑布或孤峰 → 云海与天际。

**人物**：桥面中段的小型剪影；轮廓需由天空、云或受光墙面承托。

**避免**：把桥当无支撑细线；桥宽和人物尺度不相容；下方云海没有体积层次。

### E. 曲廊引导

**用途**：行走、追寻、离去、时间流逝、竖版纵深。

**几何**：C 或 S 形铺装边界、水渠或连续光带从近景引入雾中；巨大暗檐压住顶部；岩壁为实，外侧云崖为虚。

**镜头**：28–50mm；相机位于回廊内部，沿曲线平视或轻微低视。

**层次**：暗檐／近景铺装 → 人物落脚回廊 → 重复柱列 → 雾中第二层建筑 → 云海远光。

**人物**：放在建筑暗部与亮云交界处，通常位于左或右三分区。

**避免**：曲线路径宽度忽粗忽细；曲廊穿过柱子；远处没有明确去向。

### F. 云岛鸟瞰

**用途**：地点建立、世界观、孤城、遗迹、地图感。

**几何**：宫殿群与山岩形成单一紧凑岛状体块；四周 60–70% 留给云雾、天空或光。

**镜头**：70–120mm 高位中长焦感；三分之四斜俯视；透视较平，靠雾层遮挡建立深度。

**层次**：近云 → 山崖根部 → 门阙／台基 → 宫殿群 → 古松／远云。

**人物**：可无人；若有人，只作为不可辨的微小标尺。

**避免**：把宫殿群散成多个漂浮岛；没有岩体或平台承托；云雾均匀糊住轮廓。

### G. 图腾嵌套

**用途**：星象、宿命、天命、祭祀、终章、方形封面。

**几何**：矩形画幅内嵌圆门／月轮，再嵌门阙、山峰或人物；多个形体共轴，前景自然形态负责轻微破缺。

**镜头**：85–200mm 长焦压缩感；让圆、门、峰和天体产生有意对位。

**层次**：暗崖／平台 → 人物 → 雾带 → 圆环／门阙 → 山峰／天体。

**人物**：底部中央或偏置下三分区，避免正面对镜头。

**避免**：把巨月、圆门和天门设为每次默认；月体像发光贴纸；圆框边缘被无意义裁断。

### H. 殿内观景台

**用途**：对话、奏议、宴会、静观、人物小组、室内外冷暖对比。

**几何**：顶部梁架、左右柱与下方地坪／家具形成舞台前框；圆形或矩形开口之外展开云海、松崖与远瀑。

**镜头**：28–40mm 校正广角；相机位于殿内中央或略偏置，整体深焦。

**层次**：家具／地坪 → 柱梁前框 → 人物／开放平台边缘 → 门洞 → 松崖 → 云海／远景奇观。

**人物**：2–5 人聚成一个整体，动作克制；地坪反射可强化接触关系。

**避免**：家具与建筑比例矛盾；白玉柱、龙纹、月门、瀑布同时变主角；室内暗部死黑。

## 4. 深度、尺度与负空间

### 深度阶梯

优先建立以下六层，至少保留四层：

1. 裁切到画外的暗前景：檐、柱、松、门洞边缘、岩台。
2. 尺度锚所在的真实落脚面：地坪、桥、台基、回廊、阶道。
3. 中景建筑节奏：柱列、桥面分缝、层檐、门阙。
4. 云雾遮挡带：局部吞没基座，保留关键轮廓。
5. 远端目标：主殿、山峰、瀑布、神树或天门。
6. 天空、天体或远方云平线。

通过遮挡、缩尺和空气透视降低远层对比，不用统一高斯模糊制造“景深”。

### 尺度链

完整环境镜头至少组合四类可见尺度证据：已知大小的人物或器物与门柱直接比较；台阶、铺装或柱列向远处规律递减；一个巨型构件被遮挡或延伸出画面；桥、瀑布、天阶或城区跨越云层并连接极远目标。

必须让至少三个连续标尺同时成立：

> 台阶高差／铺装分缝／桥宽 → 人物／器物 → 柱门 → 整座宫殿 → 神山／天体

单人环境镜头通常占画高 2–10%。人物多落在下方 70–95%；桥面侧视可位于画面高度 25–45%。人物虽小，仍需独立轮廓、安静背景与接触阴影。

### 负空间

- 让云海、雾、天空或暗墙占画面约 40–70%。
- 负空间必须连续、有方向、有轻微体积变化，不是纯白空缺。
- 轴向画面把空场放在道路两翼或人物周围。
- 偏置画面把空场放在实体重块的相反一侧，常用 60:40 或 40:60 平衡。
- 在人物与远端目标周围保留低细节“对比护城河”。

## 5. 镜头纪律

每次分别确定四个参数：机位高度、观察距离、俯仰方向和等效焦段。远距离不等于高机位，大全景也不自动等于俯拍；除非用户要看城区分布，否则宏大场景优先保留人眼高度或较低机位。

以下焦段均描述等效镜头感，不宣称真实 EXIF：

- **20–35mm**：轴向大厅、云庭、殿内框景；保持单一消失点和垂直线。
- **35–85mm**：侧桥、曲廊、长阶；依靠连续缩小的铺装分缝、桥宽和柱距制造距离。
- **70–120mm**：云岛鸟瞰；减弱透视，利用雾遮挡分层。
- **85–200mm**：月轮、天门、山峰对位；使用长焦压缩，不制造透明天体。

共同要求：稳定、端正、深焦、纪念碑式；避免鱼眼、荷兰角、手持倾斜、明显桶形畸变和强散景。

## 6. 画幅适配

| 画幅 | 推荐原型 | 构图调整 |
| --- | --- | --- |
| 2.35:1／21:9 | 横向悬跨、框中借景、云岛鸟瞰 | 强化左右实虚、横桥与长云平线；人物靠三分区 |
| 1.85:1／16:9 | 全部原型 | 默认电影建立镜头；保留 40–70% 连续负空间 |
| 4:3／3:2 | 殿内观景台、中轴朝圣 | 加强上下层次，减少过长横桥 |
| 1:1 | 图腾嵌套、殿内框景、云岛 | 使用圆／方几何；避免横向空场失效 |
| 4:5／3:4 | 中轴朝圣、曲廊、竖向天光 | 延长天阶、柱列、瀑布和垂直云层；标题区放顶部或一侧云墙 |
| 9:16 | 曲廊、天阶、神殿天光 | 强化高度与消失点；人物不贴底；不要把横幅简单裁窄 |

社媒封面若需要标题，先指定精确安全区及其光度与细节密度，再安排人物和奇观。文字与视觉焦点应形成上下或左右分工。

## 7. 组图与分镜节奏

可用六镜头叙事：

1. **地点建立**：云岛鸟瞰，展示宫阙如岛浮于云海。
2. **门槛揭示**：从檐下、柱间或窗内看见远方世界。
3. **进入／朝圣**：中轴长阶、云庭或长廊让人物接近目的地。
4. **侧向行旅**：横桥或曲廊打破连续对称。
5. **内部神谕**：进入深井神殿，被垂直天光锁定。
6. **象征终章**：长焦压缩天门、山峰或天体形成图腾对位。

不必每组都走完六步。至少交替轴向与偏置构图，并在相邻画面改变三项以上：相机位置、路径形态、主奇观、人物策略、光色或时间。

## 8. 构图失败模式

- 多个奇观和人物成为等权焦点。
- 人物过大、挥剑或飞跃，把环境概念图变成角色海报。
- 人物虽小，却没有接触阴影、落脚面或安静背景。
- 没有前景遮挡，完整宫殿孤零零居中，像旅游明信片。
- 云雾均匀铺满形成灰罩，没有遮挡带、开口、前后密度和清晰色彩分离。
- 左右柱廊指向不同消失点，铺装分缝或柱距缩尺不一致。
- 人物、门、柱、台阶或桥宽比例互相矛盾，巨殿像微缩模型。
- 机械完美对称，连云、树、岩和人物都镜像。
- 主殿屋顶、圆门边缘或人物被无意义截断。
- 负空间不足，装饰填满全画；或空白过度且没有云层节奏和远端目标。
- 人物与目标之间没有桥、道路、目光、光束、弧线或对角线连接。
- 整组画面重复“中央大殿＋正面小人”，缺少镜头节奏。
