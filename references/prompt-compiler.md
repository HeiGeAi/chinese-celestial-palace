## 1. 输入槽位

只要求 `subject`，其余槽位按用户要求或默认值解析：

| 槽位 | 可选内容 |
| --- | --- |
| subject | 主体、事件、一句话故事或需要迁移的对象 |
| usage | 电影概念图、封面、壁纸、海报背景、分镜、产品视觉 |
| location | 天门、主殿、悬廊、云桥、园林、藏书阁、观景台、自定义 |
| scene_scope | 单一地标、天界聚落、auto |
| composition | auto、框中借景、中轴朝圣、神殿天光、横向悬跨、曲廊、云岛鸟瞰、图腾嵌套、殿内观景台 |
| viewpoint | 平视、低机位、高机位、鸟瞰、殿内向外、远距长焦 |
| camera_height | 贴近地面、人眼高度、高位、航拍高度、auto |
| camera_distance | 近距、中距、远距、auto |
| camera_tilt | 仰拍、平视、俯拍、auto |
| focal_length | 等效广角、标准、中长焦或明确毫米数、auto |
| edge_treatment | 开放边缘、时代可信勾栏、自定义、auto |
| symmetry | 中轴、近似对称、非对称、auto |
| characters | 数量、身份、服饰、动作、尺度、是否严格无人 |
| architecture | 朝代锚点、构件、考据优先级、幻想程度 |
| celestial_mechanism | 云海托宫、悬崖筑宫、云瀑、天阶、圆形天象、天光柱、auto |
| cloud_behavior | 托举、地面雾层、穿堂、遮显、云涛、承接瀑布、捕捉逆光 |
| time_and_weather | 黎明、清晨、正午、黄昏、月夜、暴雨前后、冷雾 |
| light | 逆光、侧光、顶部光束、阴天漫射、月背光、auto |
| mood | 神圣、静谧、苍茫、悲壮、希望、威严、玄秘 |
| palette | 暖曙朱砂、冷青云白、月夜铜橙、自定义 |
| materials | 朱漆木、黛瓦、白石、山岩、铜饰、湿地面等 |
| aspect_ratio | 2.35:1、1.85:1、16:9、4:3、1:1、4:5、3:4、9:16 |
| render_style | 写实数字绘景、影视概念设计、绘画感写实 |
| fidelity_mode | 严格参考气质、同源变体、大胆扩展 |
| text_requirement | 无，或精确文案、位置、行数、字体气质、颜色与留白区 |
| exclusions | 用户明确不希望出现的内容 |
| target_model | auto、自然语言模型、Midjourney、FLUX、SDXL、文字优先模型等 |
| variation_count | 1–4，或用户指定数量 |

默认值：1.85:1、神话化但可信的中国木构、一名极小人物、黎明／清晨、一个主奇观、云海承担两种空间功能、高明度云白与浅石色作中性基底、克制朱砂与矿物青绿作局部色彩、`edge_treatment` 为开放边缘、电影级写实数字绘景。

## 2. 编译顺序

按模型关注权重从高到低排列信息：

1. 整体场景、主体和用途
2. 主构图，以及机位高度、拍摄距离、仰俯角和焦段
3. 前景—中景—远景的明确空间关系
4. 中国木构形态与承托机制
5. 人物或物件的数量、位置、尺度与动作
6. 云的体积、遮挡、流动与受光职责
7. 唯一主奇观
8. 主光源、冷暖关系与色盘
9. 木、瓦、石、丝绸和湿润表面的材质
10. 摄影、空气透视、动态范围与渲染质感
11. 留字区、文字和必须避免项

画幅比例必须出现在成品提示词首句，并改变实际构图路径，不只作为末尾标签。“远距”不等于“高机位”，“大全景”不等于“鸟瞰”。优先写“位于、穿过、遮挡、延伸到、占据左侧、沿中轴收束”等空间动词。减少“唯美、梦幻、震撼、史诗、极致”等不可执行形容词。

## 3. 模型中立母模板

把占位符全部解析后再交付，不保留花括号：

```text
{aspect_ratio}画幅，一幅用于{usage}的中式天宫场景：{subject}发生在{location}。

采用{composition}。相机高度为{camera_height}，距离为{camera_distance}，仰俯角为{camera_tilt}，焦段为{focal_length}；{foreground_frame}形成前景边界，{leading_line}把视线引向{focal_point}；前景、中景、云雾遮挡带和远景明确分离，并在{negative_space_position}保留大面积低对比负空间。

空间由可信的神话化中国古典木构建立：{architecture_components}，具有宽阔低缓的宫殿屋面、深远出檐、清晰柱网、层叠斗拱、统一开间与{materials}。整个宫阙通过{celestial_mechanism}存在于高空，建筑的台基、山岩、巨柱或桥梁提供可读的承托关系。桥、长阶、平台与悬廊采用{edge_treatment}；默认保持开放边缘，只有用户明确要求或严格考据锁定时才改用时代可信构件。

{character_description}位于{character_position}，脚下是{contact_surface}，人物／物件尺度克制，用来显示天地与宫阙的巨大比例，而不是成为近景肖像主体。用台阶与人物、门洞与柱径、重复开间的远近收缩、建筑与天际的占幅关系建立至少四类可见尺度证据。

若{scene_scope}为天界聚落，画面必须同时看到统领主建筑、次级宫阙群、可通行的桥阶或庭院系统，以及向远方继续的居住迹象，不得退化为一座孤立主殿。

云气不是背景装饰：近云{near_cloud_behavior}，中景云{mid_cloud_behavior}，远云{far_cloud_behavior}；云层既{cloud_role_1}又{cloud_role_2}，与柱廊、桥底、崖壁和光线产生真实遮挡、消光与体积层次。

画面只使用一个主神迹——{dominant_spectacle}。由{light_source}提供唯一主光，形成{light_behavior}、真实体积散射和空气透视；云顶与受光面呈{highlight_color}，云底和阴影保持{shadow_color}，整体采用{palette}的克制冷暖关系。

木、瓦、石、丝绸与湿润表面具有可信质感；远层因空气密度自然降低对比和饱和度。整体庄严、静谧、苍茫，强调建筑节奏、尺度反差、云海留白与叙事瞬间；高端影视概念设计、写实数字绘景、适度绘画性、深焦静态电影镜头、自然动态范围、柔和高光滚降、清晰主次，{camera_language}。

{text_and_output_constraints}
```

若主题是产品、器物或现代设备，不要强行把它改成古代物件。让原主体保持清晰身份，再用月洞框景、白石台、朱木暗框、云反射和尺度关系完成风格迁移。

## 4. 动态负面约束

按本次方案选择必要项，不把完整词库机械粘贴到每条提示词。

### 文化与结构

避免泛东亚混搭、日式鸟居／神社／城堡轮廓、韩屋、东南亚尖顶或佛塔、哥特教堂、欧式城堡、希腊罗马柱；避免随机叠屋顶、融化斗拱、无支撑飞檐、弯折柱栏、柱子穿过阶梯、开间不一致、夸张角状屋檐和错误透视。默认排除栏杆、护栏、围栏和栏板，使高空边缘保持开放。

### 云、自然与奇观

避免棉花球云、肥皂泡云、平面祥云贴图、烟雾爆炸、硬边云剪影、无雾遮挡的漂浮山、无源或逆流瀑布、重复月亮、透明贴纸月亮、盆栽松和无关的阿尔卑斯山景。

### 美学与渲染

避免无关龙凤麒麟、灯笼海、满屏金饰、随机书法、霓虹 RGB、彩虹光、魔法阵、发光武器、仙尘、游戏 UI、手游宣传图、动漫、Q 版、塑料 CG、过度橙青、灰雾蒙片、脏灰滤镜、色彩粘连不分、无来源泛光、过锐 HDR、死黑暗部与过曝天空。

### 人物与输出瑕疵

避免近景英雄肖像、无关人群、战斗姿势、现代 cosplay 质感、和服轮廓、错误左衽、人物漂浮、肢体和面部畸形、重复人物；避免随机文字、字幕、水印、logo、视频黑边、低清压缩、色带和锐化光晕。

### 条件式排除

- 未选月轮时，排除巨月与圆形传送门。
- 用户要求无人时，排除人物和人形剪影。
- 冷雾场景排除橙色夕阳；暖曙场景排除扁平阴天光。
- 用户明确要求龙、霓虹、群像或文字时，移除相应禁止项，并让它成为有叙事原因的受控元素。
- 用户明确要求栏杆、护栏、围栏或传统勾栏，或将它锁定为严格考据构件时，移除开放边缘的相应排除项，并保留时代可信的形制；不把现代金属护栏当作传统勾栏。

## 5. 模型适配器

### 自然语言图像模型

- 保留完整句子和明确空间关系。
- 使用“位于、穿过、遮挡、沿着、占据”等关系词。
- 把“必须避免”写成简短自然语言，不依赖权重符号。
- 文字任务单列精确文案、位置、行数、字体气质和留白区；无文字任务明确禁止随机文字。

### Midjourney 类短语模型

- 压缩为：主体场景 → 构图 → 中国木构 → 云的职责 → 尺度锚 → 主光 → 色盘 → 摄影／渲染。
- 把负面内容映射为账户当前支持的排除语法；不要写死模型版本。
- 使用当前支持的宽高比；风格化控制保持低到中等，避免压过构图。
- 权重只用于 1–3 个关键短语，不给每个质量词加权。

### FLUX 类自然句工作流

- 使用流畅自然句，明确几何和空间因果。
- 优先正向约束；负面字段是否生效取决于具体工作流，因此另附独立排除清单。
- 避免 booru 标签堆、重复中英关键词和大量括号权重。

### SDXL／扩散工作流

- 正向提示按“场景—构图—建筑—人物—云—光—材质—质量”分段。
- 单独输出 negative prompt。
- 只对主构图或中国木构使用少量温和权重；不要让权重代替空间描述。
- LoRA、ControlNet、参考图强度等放在控制建议，不写进语义母提示词。
- 需要锁定柱廊、桥梁和楼梯透视时，优先建议深度或线稿控制。

### 中文自然语言模型

- 使用完整、短句式中文；明确左右、前后、尺度和遮挡。
- 强化“中国古典木构宫殿、宽缓屋面、深远出檐、成列朱柱”，少用泛称“亚洲寺庙”。
- 避免同一组中英关键词重复多次。
- 单列“画面中不要出现”。

### 文字优先模型

- 把背景提示与文字规范拆开。
- 文字规范包含精确文案、字数、位置、行数、字体气质、颜色和安全区。
- 主动预留低细节云海、天空或暗墙；不要让标题与人物、斗拱或高反差云边重叠。

### 未知模型回退

输出一段自然语言主提示词、一段独立排除词，以及画幅、人物数量、主光源和主构图四项控制。不要使用任何专属参数。

## 6. 默认输出契约

### 创意定调

用一句话指出故事动作、主构图和唯一主奇观。

### 构图蓝图

至少明确：构图原型、机位高度、拍摄距离、仰俯角、焦段、前景、中景、云雾遮挡带、远景目标、主焦点、四类可见尺度证据、开放边缘或用户覆盖、负空间位置、主光、色盘。

### 主提示词

输出完整成品，不使用占位符，不混入解释性括号，不重复同义质量词。

### 负面提示词／必须避免

只保留与本次设计相关的文化、结构、人物、渲染和输出排除项。

### 生成控制

写明画幅、文字安全区、人物数量、主构图、机位四参数和主光。目标平台明确时才给模型适配；无法确认的参数不要猜。

### 变化旋钮

给出 2–4 个单变量或双变量变化，例如“暖曙→冷雾”“单人→严格无人”“35mm 框景→85mm 长焦对位”。

### 质检

只报告总分、硬失败数量、关键假设和已修复风险，不展示内部思维过程。

## 8. 变化与系列控制

保持世界观一致的变量：建筑语汇、基础色盘、云层物理、材质规则、人物身份。

优先轮换的变量：

- 构图：中轴、框景、横跨、曲廊、鸟瞰、图腾嵌套
- 相机：檐下、桥头、回廊内部、高位、远距长焦
- 奇观：天光、云瀑、神树、天阶、圆门、孤峰；每张只选一个
- 光色：暖曙、冷雾、月夜铜橙、暗殿白光
- 人物：无人、孤行者、二三人小组、秩序化队列
- 负空间：中央、道路两翼、实体相反一侧、圆门内部

系列相邻画面至少改变上述三项，但不要同时改变建筑时代、人物身份和基础材质，否则会失去同源感。
